# Productivity Dashboard Context

A personal productivity workspace integrating a Pomodoro focus timer, task management, and analytics dashboard.

## Language

**Workspace**:
The single-user personal dashboard operating locally within a user's browser session.
_Avoid_: Account, tenant, organization

**Task**:
An actionable todo item with optional checklist sub-items, priority, deadline, and stopwatch tracking.
_Avoid_: Ticket, issue, story

**Focus Session**:
A timed Pomodoro duration interval recorded to measure productivity.
_Avoid_: Interval, work block, log

**Night Glass**:
The fixed dark UI visual aesthetic utilizing glassmorphism gradients and frosted background panels.
_Avoid_: Theme selector, light mode, dark mode toggle
